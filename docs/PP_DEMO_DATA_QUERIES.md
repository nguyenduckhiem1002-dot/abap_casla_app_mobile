# Kiểm tra dữ liệu demo `ZCL_PP_MOCK_CONFIRM_DATA`

Class chỉ dùng hai mobile user đã có là `manager_67310035` và `duck`; không tạo hoặc sửa
credential. Khi chạy, class tạo Work ID dùng chung, role/function cần thiết và một operation
demo có tổng sản lượng `100 ST`. `ST` là mã nội bộ SAP cho piece; OData có thể trả mã ISO
`PCE` ra ngoài.

| User | Worker ID | Role | Được giao | Đã hoàn thành | Còn lại |
| --- | --- | --- | ---: | ---: | ---: |
| `manager_67310035` | `67310035` | `PP_MANAGER` | Người giao việc | — | — |
| `duck` | `HD000001` | `PP_OPERATOR` | 100 ST | 25 ST | 75 ST |

## 1. Kiểm tra hai user

```sql
SELECT
  ZTB_MOB_USER~CLIENT,
  ZTB_MOB_USER~USER_UUID,
  ZTB_MOB_USER~USERNAME,
  ZTB_MOB_USER~NORMALIZED_USERNAME,
  ZTB_MOB_USER~FULL_NAME,
  ZTB_MOB_USER~EMAIL,
  ZTB_MOB_USER~WORKER_ID,
  ZTB_MOB_USER~STATUS,
  ZTB_MOB_USER~LAST_LOGIN_AT
FROM
  ZTB_MOB_USER
WHERE
  ZTB_MOB_USER~NORMALIZED_USERNAME IN ('manager_67310035', 'duck')
```

## 5. Kiểm tra ledger giao và xác nhận sản lượng

```sql
SELECT
  ZTB_PP_ALLOC_TXN~CLIENT,
  ZTB_PP_ALLOC_TXN~TRANSACTION_UUID,
  ZTB_PP_ALLOC_TXN~OPERATION_UUID,
  ZTB_PP_ALLOC_TXN~ORIGINAL_TRANSACTION_UUID,
  ZTB_PP_ALLOC_TXN~ACTOR_USER_UUID,
  ZTB_PP_ALLOC_TXN~VERIFIED_WORKER_USER_UUID,
  ZTB_PP_ALLOC_TXN~TRANSACTION_TYPE,
  ZTB_PP_ALLOC_TXN~ORIGINAL_TRANSACTION_TYPE,
  ZTB_PP_ALLOC_TXN~TO_WORKER_ID,
  ZTB_PP_ALLOC_TXN~WORKER_ID,
  ZTB_PP_ALLOC_TXN~QUANTITY,
  ZTB_PP_ALLOC_TXN~UOM,
  ZTB_PP_ALLOC_TXN~EXECUTION_DATE,
  ZTB_PP_ALLOC_TXN~TRANSACTION_STATUS,
  ZTB_PP_ALLOC_TXN~REASON_CODE,
  ZTB_PP_ALLOC_TXN~REASON_TEXT,
  ZTB_PP_ALLOC_TXN~SOURCE_CHANNEL
FROM
  ZTB_PP_ALLOC_TXN
WHERE
  ZTB_PP_ALLOC_TXN~REASON_CODE = 'DEMO_VIEW_QTY'
```

Các dòng `CONFIRM` trỏ `ORIGINAL_TRANSACTION_UUID` về dòng `INITIAL_ASSIGN` tương ứng. Liên
kết này là bắt buộc để API lịch sử của quản lý gom đúng dữ liệu đội.

Mỗi lần chạy, class xóa bộ dữ liệu cũ của `DEMO00000001/0010` theo thứ tự ledger, balance,
operation rồi tạo lại đúng một bộ mới với UoM `ST`. User, role và Work ID không bị xóa.

> Đây là dữ liệu lịch sử mock trong bảng Z để demo màn xem sản lượng. Lệnh
> `DEMO00000001` không phải production order chuẩn SAP, vì vậy không dùng nó để demo thao tác
> xác nhận trực tiếp lên SAP.
