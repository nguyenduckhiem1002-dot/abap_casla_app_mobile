# Query dữ liệu cho `ZCL_PP_MOCK_CONFIRM_DATA`

Class ưu tiên `requested_worker` nếu constant này có giá trị. Khi để trống, class tự chọn
worker đang hiệu lực và chưa liên kết với mobile user.

## 1. Worker thực tế và phạm vi làm việc

```sql
SELECT
  ZI_PP_WORKERREF~WORKERUUID,
  ZI_PP_WORKERREF~WORKERID,
  ZI_PP_WORKERREF~WORKERNAME,
  ZI_PP_WORKERREF~PLANT,
  ZI_PP_WORKERREF~WORKCENTER,
  ZI_PP_WORKERREF~VALIDFROM,
  ZI_PP_WORKERREF~VALIDTO
FROM
  ZI_PP_WORKERREF
```

Chọn một `WORKERID` còn hiệu lực rồi điền vào constant `requested_worker`. Không dùng worker
đã xuất hiện trong kết quả query tiếp theo.

## 5. Kiểm tra credential sau khi tạo

Không chia sẻ `PASSWORD_HASH` hoặc `PASSWORD_SALT`. Chỉ dùng query này để kiểm tra trạng thái
credential và thuật toán hash.

```sql
SELECT
  ZTB_MOB_CRED~CLIENT,
  ZTB_MOB_CRED~USER_UUID,
  ZTB_MOB_CRED~HASH_ALGORITHM,
  ZTB_MOB_CRED~HASH_ITERATIONS,
  ZTB_MOB_CRED~PASSWORD_CHANGED_AT,
  ZTB_MOB_CRED~CREDENTIAL_STATUS
FROM
  ZTB_MOB_CRED
```

Sau khi class chạy thành công, đăng nhập bằng temporary password được in ở ABAP Console rồi
gọi `changePassword`. Tài khoản mới luôn có `PASSWORD_CHANGE_REQUIRED = X`.

## 6. Kiểm tra security config bắt buộc

Không query hoặc chia sẻ `CONFIG_VALUE`. Chỉ kiểm tra hai key `PASSWORD_PEPPER` và
`TOKEN_SECRET` tồn tại, có `IS_ACTIVE = X`.

```sql
SELECT
  ZTB_MOB_CONFIG~CLIENT,
  ZTB_MOB_CONFIG~CONFIG_KEY,
  ZTB_MOB_CONFIG~IS_ACTIVE,
  ZTB_MOB_CONFIG~CHANGED_BY,
  ZTB_MOB_CONFIG~CHANGED_AT
FROM
  ZTB_MOB_CONFIG
```
